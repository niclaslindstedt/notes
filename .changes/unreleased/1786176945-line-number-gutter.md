---
type: Changed
title: Tighter line-number gutter
---

The line-number gutter now reserves only the width the note's highest number
needs — a nine-line note gives the writing column a digit more room than a
ten-line one — each number sits beside the first row of the line it belongs to
however far that line wraps, and the whole column beside a line is a press
target that selects it from the start.
