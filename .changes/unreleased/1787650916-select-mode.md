---
type: Added
title: Select mode
---

A new button left of Find turns the note into a list of lines you pick from — press to take a line, press it again to give it back, drag the rail down the left edge to take a run of them, then format, cut, copy or delete it from the four buttons the header unfolds while lines are picked, type over it, or style every line at once — and the lit button stays on the header while the mode is on, so leaving it again is always one press away.
