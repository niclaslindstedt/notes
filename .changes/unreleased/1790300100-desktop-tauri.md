---
type: Changed
title: A lighter desktop app
---

The desktop download is now built on the system's own web engine instead of carrying a copy of Chromium, so it is a fraction of the size. It installs with a normal installer (`.exe`, `.dmg`, `.AppImage` or `.deb`) rather than a zip, and Dropbox sign-in still opens your usual browser and hands the result back to the app. The window still reopens where you left it.
