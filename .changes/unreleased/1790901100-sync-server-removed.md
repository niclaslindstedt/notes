---
type: Removed
title: Self-hosted sync server
---

The self-hosted sync server is no longer one of the places notes can be kept, and the app no longer pairs with one, scans its QR code or asks for the camera. A device that was set to it now opens on the notes kept in this browser, as with sync off; your notes stay as plain files in the folder the server was pointed at, and a Nextcloud you run remains the way to sync with a server of your own.
