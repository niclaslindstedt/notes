---
type: Added
title: Select an image to copy, cut or delete it
---

Clicking an image in a note now selects it, so Ctrl/Cmd+C puts the picture itself on your clipboard, Ctrl/Cmd+X moves it to another note without asking about the file, and Delete removes it from the note and from storage outright — with the same actions on a right-click or a long press, and a warning when a pasted attachment is no longer stored anywhere.
