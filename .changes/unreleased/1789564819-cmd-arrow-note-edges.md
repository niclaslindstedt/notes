---
type: Changed
title: Cmd+↑ / ↓ goes to the top and bottom of a note
---

With nothing selected, Ctrl/Cmd+↑ / ↓ now jumps to the start or end of the note instead of adding a cursor — growing a column from a bare caret is Ctrl/Cmd+Alt+↑ / ↓, and the plain press still grows a column that is already up.
